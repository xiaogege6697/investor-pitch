# 句式变体与实例

同一项目对不同对象，重心完全不同。先定类型，再套句式。

## 一、融资型（财务 VC/PE）

**对方关心**：能不能退、多久退、贵不贵。
**重心**：增长数据、客户质量、下一轮谁接。
**不要讲**：税收、就业、产线（他不关心）。

```
X总，[方向] 这个方向您关注吗？[一句最硬验证]，本轮 [金额/轮次]

[技术定位]，[客户验证]，[需求量级]。[阶段轮次]，拟融[X万]、投后[Y亿]，项目在[地点]
```

真实样本：

> 张总，大模型数采手套这个方向您关注吗？间接供货OpenAI，有扩产能落产线的诉求
>
> 镓铟液态金属全栈自研数采手套，已进头部AI公司供应链，2027年意向需求数千套量级。早期项目，种子轮，拟融2000万、投后约1亿，项目在深圳

**收尾**：约 15 分钟电话，不给 BP 摘要。

---

## 二、落地型（地方国资 / 招商 / 园区平台）

**对方关心**：固投多少、什么时候投产、税收和就业、返投比例。
**重心**：钱怎么花在当地、能带来什么产业配套。
**不要讲**：估值、退出（他不关心，甚至反感）。

```
X总，[项目] 看吗？企业能落 [产线数量/产能]，固投 [金额]，[区域] 都可以

[技术定位]，[客户验证]。本轮 [阶段]，拟落 [城市/区域]，用地 [X 亩] / 产线 [X] 条
```

真实样本：

> 邹总，线控底盘电机的项目看吗，企业能落地三条产线，固投比例1:1.2，长三角都可以
>
> 章总，线控底盘电机的项目看吗，企业想落地三条产线，固投比例1:1.2

**收尾**：约线下见面，带选址方案。

**注意**：地方平台常卡收入门槛（例：某平台要求 2022 年收入 5000 万以上）。天使期不达标时，正确做法是**只谈试点基地，不谈股权**，不要硬拗。

---

## 三、产业合作型（产业资本 / 央企 / 上市公司战投）

**对方关心**：这东西对我的主业是加法还是威胁。
**重心**：**先证明不是竞品，再讲互补**。
**不要讲**：我要成为行业龙头（他听成威胁）。

```
X总，[方向] 您这边在看吗？我们做的是 [补位环节]，跟 [他已投/他主业] 是配套关系

[技术定位]，[客户验证]。想找 [具体场景] 做试点，不着急融资
```

真实样本（结构仿写）：

> 薛总，内河船端智驾模块您这边在看吗？我们做的是给船做加法的那一层，不是造船，跟贵方已投的航运企业是配套关系
>
> 船端智能通导全栈自研，已装内河集装箱船 30+ 艘。想找一条固定航线做自动化船队试点，本轮融资不急

**收尾**：要一个试点，不要钱。

**关键**：动笔前必须查这家机构**已投了谁**。已投同类的，口径必须改成"配套"；改不了就别推这家。

---

## 四、引荐型（有中间资源的人）

**对方关心**：我转发出去会不会丢人。
**重心**：给他一句能直接复制粘贴的话。
**不要讲**：长篇背景（他不会读，也不会转）。

```
X总，[一句话项目定性]，想请您帮忙转给 [机构/人]。下面这段可以直接转：

「[40 字以内，能独立成立的项目介绍]」
```

真实样本（结构仿写）：

> 汤总，有个内河船舶自动驾驶的项目，想请您帮忙转给某基金那边。下面这段您可以直接转：
>
> 「某集团孵化的内河船舶自动驾驶项目，船端智能通导全栈自研，已装内河船 30+ 艘，天使轮已到账，现在找长三角的试航航道和港口场景」

**收尾**：只要求转发，不要求他判断、不要求他背书。

**为什么这么写**：10-30 实测发"方便引荐一下该基金同事吗"，4 天零回应。开放式请求把"想怎么介绍你"的思考成本推给了对方。给现成文案，他只需按转发。

---

## 五、跟进型（对方已读不回）

**绝对不要重发原句。** 重发等于催债。

结构固定：**一个新信息 + 一个台阶**。

```
X总，上次提的 [项目] 补一条：[新进展]。您那边要是 [条件不符]，我就不占您时间了
```

真实样本（本人用过的句式）：

> 汤总，上次提的智能船舶项目补一条：刚完成数千万天使轮，某产业基金投的，现在主要精力在配落地，长三角和京杭运河几条线在谈试点。某地那边想先了解下基金对智能船舶这类有没有口径，不合适我就不占您时间了

三个要件：

1. **新信息**——融资到账、新客户、新试点，必须是真的新的；
2. **降低他的判断成本**——把诉求缩到一个具体的"有没有口径"；
3. **给台阶**——"不合适我就不占您时间"，让他可以低成本结束对话。

**时间**：至少隔 3 天。同一件事最多追两次，两次没回就转别人。

---

## 六、反面清单（实测无效的写法）

| 写法 | 为什么无效 |
|---|---|
| "方便引荐一下 XX 吗" | 开放式请求，把思考成本推给对方。实测 4 天零回应 |
| "我们技术国内领先" | 无第三方支撑，等于没说 |
| "附件是我们的 BP，请查收" | 第一条就发文件，对方不会打开 |
| "不知您是否方便抽空了解一下" | 全是虚词，没有一个事实 |
| 一条消息写 200 字 | 微信场景下会被折叠，实测本人字数中位数只有 38 字 |
| "打扰了""不占您时间"滥用 | 本人真实样本里几乎不用，用了反而显得在推销 |
